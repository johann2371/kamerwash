# AquaWash - Service de Lavage à Domicile

Application web de réservation et de gestion de prestations de lavage à domicile (voitures, canapés, tapis, vitres).

## Technologies
- **Backend**: Laravel 11 (PHP 8.2+) / API RESTful
- **Frontend**: React 18 / Vite / Tailwind CSS
- **Base de données**: SQLite / MySQL
